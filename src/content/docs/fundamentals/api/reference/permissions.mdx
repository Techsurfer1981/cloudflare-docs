Permissions are segmented into three categories based on resource:

- Zone permissions
- Account permissions
- User permissions

Each category contains permission groups related to those resources. DNS permissions belong to the Zone category, while Billing permissions belong to the Account category. Below is a list of the available token permissions.

To obtain an updated list of token permissions, including the permission ID and the scope of each permission, use the [List permission groups](/api/resources/user/subresources/tokens/subresources/permission_groups/methods/list/) endpoint.

:::note[Logpush API permissions]

Logpush job management requires specific **Logs** permissions. General zone or account read access is not sufficient.

- **Zone Logs Read** — Required to read zone-scoped Logpush jobs (for example, `http_requests`, `firewall_events`).
- **Zone Logs Write** — Required to create, update, or delete zone-scoped Logpush jobs.
- **Account Logs Read** — Required to read account-scoped Logpush jobs (for example, `audit_logs`, `gateway_http`).
- **Account Logs Write** — Required to create, update, or delete account-scoped Logpush jobs.

A token with only **Zone Read** or **Account Settings Read** will receive an `Authentication error` (code `10000`) when calling Logpush endpoints.
:::
